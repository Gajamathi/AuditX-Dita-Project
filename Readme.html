AuditX Documentation Project Overview AuditX is a fictional audit and verification platform documented using DITA and topic-based authoring principles. This project demonstrates how I structure complex product information into role-based, task-oriented, and reusable documentation. Documentation Scope The project includes: * Product overview * Role-based documentation * Task-based procedures * Workflow documentation * Reference content * Troubleshooting * Glossary content Information Architecture The documentation is organized into role-based guides: * Administrator Guide * Supervisor Guide * Operator Guide The project also includes reusable content and DITA maps to organize and manage documentation topics. Documentation Topics Key documentation topics include: * Creating a site * Creating users * Managing user roles * Creating an order verification workflow * Resetting a password * Understanding reports * Troubleshooting common issues Tools and Technologies * DITA XML * Oxygen XML Editor * DITA Maps * Topic-based authoring * Content reuse What This Project Demonstrates This project demonstrates my ability to: * Structure complex information * Create task-based documentation * Organize content for different user roles * Develop reusable documentation topics * Build documentation using DITA XML * Create and manage documentation maps Repository Structure ```text topics/ Task, concept, and reference topics reusables/ Reusable documentation components images/ Images used throughout the documentation *.ditamap Documentation maps used to organize guides ``` Project Note AuditX is a portfolio project created to demonstrate structured technical documentation and DITA-based authoring.
