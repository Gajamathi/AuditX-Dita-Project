# AuditX Documentation Project

## Overview

AuditX is a fictional audit and verification platform documented using **DITA** and **topic-based authoring principles**.

This project demonstrates how I structure complex product information into role-based, task-oriented, and reusable documentation. The documentation is organized to support different user roles and includes conceptual information, procedures, workflows, reference content, troubleshooting, and glossary content.

## Information Architecture

The documentation is organized using DITA maps and topic-based authoring principles.

```text
AuditX Documentation
│
├── Product Information
│   ├── Product Overview
│   └── User Roles
│
├── Administrator Guide
│   ├── Create Sites
│   ├── Create Users
│   └── Manage User Roles
│
├── Supervisor Guide
│   └── Create and Manage Workflows
│
├── Operator Guide
│   └── Role-Specific Tasks
│
└── Supporting Content
    ├── Reports Reference
    ├── Troubleshooting
    └── Glossary
```

The documentation structure uses modular topics and DITA maps to organize content and support scalable documentation development.

## Documentation Approach

The project follows topic-based authoring principles to separate information into reusable and focused topics.

The documentation includes different types of content, such as:

- **Concept topics** for explaining product information and concepts
- **Task topics** for guiding users through procedures
- **Reference topics** for providing structured reference information

This approach helps create documentation that is easier to organize, maintain, and reuse.
